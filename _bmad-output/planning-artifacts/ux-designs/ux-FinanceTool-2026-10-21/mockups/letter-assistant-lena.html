The letter is a fixed template filled from the confirmed facts. The LLM writes no letter text. An objection would need a legal assessment, so Fine refuses it.

LLM as an untrusted edge. The LLM only reads the letter and proposes values. Personal identifiers are masked before it sees the text. A deterministic check finds every value in the letter, and the customer confirms before anything is used.
Numbers from the deterministic core. The +124 EUR and −214 EUR come from the forecast engine, using the confirmed facts. The explanation passes the same compliance checks as every other answer.
Autonomy stays with the customer. A letter to a third party is capped at "recommend" (L1). Fine prepares it; the customer decides, signs and sends it. Instructions hidden in a letter cannot trigger any action.
