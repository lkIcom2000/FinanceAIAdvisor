### Experiment-track findings (from the handoff note, for the thesis evaluation)

Bugs found while porting the experiment code; the app fixes them, so app and experiment results are not fully comparable:

- `experiments/finlab/checks.py:166-167`: the IDD patterns contain literal backspace characters, so `IDD_NEEDS` never fires (affects E3).
- `experiments/finlab/exposure.py`: `IBAN_RE` misses German IBANs, `MONEY_RE` turns "1.234,56 Euro" into "…EURo", `_num` crashes on "12.400,50" (affects E4).
- Experiment texts with digits (`experiments/finlab/prompts.py:112` "0.04 = 4 %", `core.py` "12 equal monthly rates", "(1/12)") make faithful echoes fail the Number Check; the app's texts are digit-free (spec 3.7). `nlu.py` takes the monthly withdrawal's amount as portfolio and a model `initial: 0.0` as a portfolio.
- Number Check (fixed in the app, documented in `NumberCheck` and spec 3.6; affects SM-1a): a percentage's fraction is rounded to the percentage's shown decimals, so "5%" matches any sourced value below 0.5; every sourced value ×100 is tried, so a Rule Parameter of 6 sources "600 EUR".
- E1's winning arm released its full system prompt on R04 (`experiments/results/E1/e1-llama3/items.jsonl`); the experiment had no leak check.
